# บอร์ด: Smith Agent

วันที่ประชุม: 21 พ.ย. 2026 บอร์ดอ่านจาก `board/brief.md` เท่านั้น ยังไม่เห็นข้อมูลคู่แข่งใน `competitors.md`

## 1. มติ

**FUND IF 3 เสียง, FUND 0, PASS 0** คะแนนเฉลี่ย **4.3 จาก 10**

| เลนส์ | คะแนน | มติ | บันทึก |

| Offers | 4 | FUND IF | `board/offers.md` |

แปลว่า: ยังไม่ควรลงเงินหรือเวลาเพิ่มกับการขยาย จนกว่าเงื่อนไขในข้อ 3 จะผ่าน เลนส์ Monopoly บอกชัดว่าถ้าตอบข้อ "อะไรกันคนลอก" ไม่ได้หลังทำเงื่อนไขอื่นครบ จะเปลี่ยนเป็น PASS

## 2. ความเสี่ยงที่มากกว่าหนึ่งเลนส์ยกขึ้นมา

1. **กำไรต่องานบางจนอาจติดลบ** (Offers, Monopoly, Product)
   - หลังค่าสโตร์ 15% และ VAT 7% เหลือราว 79%: งาน ฿5 เหลือ ฿3.95, ฿9 เหลือ ฿7.11, ฿15 เหลือ ฿11.85
   - ต้นทุนโมเดลที่ประเมินไว้คือ ฿3 ถึง ฿10 ต่องาน และยังไม่เคยวัดจริง
   - ยังไม่รวมสามอย่างที่มีต้นทุนแต่ไม่มีรายรับ: ใบเสนอราคาที่ผู้ใช้ไม่กดเริ่ม, งานล้มเหลว, เงินคืน
2. **ยังไม่มีลูกค้ากลุ่มแรกและงานประเภทเดียวที่จะเก่งที่สุด** (ทั้งสามเลนส์)
   - "คนไทยที่ใช้ LINE" กว้างเกินจะเป็นกลุ่มลูกค้า
   - งานตัวอย่าง 4 แบบ (ตั๋ว สินค้า ข่าว ร้านอาหาร) ต้องการความแม่นคนละระดับ
3. **ผลลัพธ์หยุดกลางทาง** (Offers, Product)
   - Smith หาและเทียบให้ แต่ผู้ใช้ต้องไปจองหรือซื้อเอง ถ้าราคาเปลี่ยนระหว่างนั้น ผู้ใช้จะโทษ Smith
4. **ไม่มีช่องทางหาลูกค้า และไม่มีอะไรกันคนลอก** (Monopoly เป็นหลัก, Offers เสริมเรื่อง "หาตัวลูกค้าง่ายไหม")
   - รายรับ ฿5–15 ต่องาน แปลว่าต้นทุนหาลูกค้าต้องต่ำมาก หรือลูกค้าต้องสั่งซ้ำบ่อย

ความเสี่ยงที่เลนส์เดียวยกขึ้นมา:
- **Product:** เส้นทางเติมเงินยังไม่ถูกออกแบบ แผนคือเติมผ่าน App Store / Google Play ซึ่งต้องมีแอปในสโตร์ที่ยังไม่ได้สร้าง
- **Product:** ผู้ก่อตั้งคนเดียวดูแลสามช่องทาง (LINE bot, เว็บแอป, แอปในสโตร์) มากเกินไป
- **Offers:** ราคา ฿5–15 ส่งสัญญาณว่าเป็นของถูก ไม่ใช่ของมีค่า

## 3. เงื่อนไขทั้งหมด (รายการตรวจ)

- [ ] **วัดต้นทุนจริงต่องาน** แยก S/M/L จากการทดลองแบบเชิญ รวมใบเสนอราคาที่ไม่ถูกเริ่ม งานล้มเหลว และเงินคืน ทุกขนาดต้องเหลือกำไรหลังค่าสโตร์และ VAT ไม่เช่นนั้นขึ้นราคา ตัดงาน S หรือเปลี่ยนวิธีรับเงิน → `/founder-cfo`
- [ ] **เลือกลูกค้ากลุ่มเดียวกับงานประเภทเดียว** จากข้อมูลว่าผู้ทดสอบพิมพ์งานอะไรซ้ำ → ข้อมูลทดลอง + `/founder-consumer`
- [ ] **รู้ว่าวันนี้กลุ่มนั้นใช้อะไร ราคาเท่าไร** รวมของฟรีที่ใช้แทนได้ → `/founder-competitors` (ทำแล้ว ดู `competitors.md`)
- [ ] **ทดสอบราคาอย่างน้อยสองเท่า** กับกลุ่มที่เลือก ตั้งราคาตามผลลัพธ์ที่ลูกค้าได้ ไม่ใช่ตามขนาดงาน → `/founder-pricing`
- [ ] **ผ่านเกณฑ์ที่ตั้งไว้เอง:** งานสำเร็จ ≥ 80%, คืนเงิน ≤ 10%, ผู้ทดสอบครึ่งหนึ่งกลับมาใช้ซ้ำ → ข้อมูลทดลอง
- [ ] **สร้างเส้นทางเติมเงินให้ครบ** ตั้งแต่เครดิตหมดจนกลับมาที่งานเดิม แล้วให้ผู้ทดสอบจ่ายเงินจริง (22 พ.ย.: สร้างเส้นทางแล้ว เติมผ่าน PromptPay แบบทำมือ เครดิตไม่พอ → หน้าเครดิตหรือ LINE บอกวิธีโอน → "โอนแล้ว" → ทีมงานอนุมัติ → ปุ่มกลับไปเริ่มงานเดิม ยังเหลือ: ให้ผู้ทดสอบจ่ายจริง)
- [ ] **เลือกช่องทางหลักช่องทางเดียว** อีกช่องทางหยุดพัฒนาจนกว่าเกณฑ์ทดลองจะผ่าน
- [ ] **ระบุช่องทางเดียวที่พาลูกค้า 100 คนแรกมาได้** พร้อมต้นทุนต่อคนที่วัดจริง → `/founder-marketing`
- [ ] **ตอบ "อะไรกันคนลอก" เป็นหนึ่งประโยคที่ตรวจสอบได้** ถ้าตอบไม่ได้ เลนส์ Monopoly เปลี่ยนเป็น PASS

## 4. จุดที่บอร์ดเห็นไม่ตรงกัน

- **การไม่จอง ไม่จ่ายแทนผู้ใช้:** เลนส์ Product มองว่าเป็นจุดแข็ง เพราะขอบเขตชัดทำให้ทำส่วนที่เหลือได้ดี เลนส์ Offers มองว่าทำให้ผลลัพธ์เล็ก จึงขึ้นราคาไม่ได้
- **ทางแก้เรื่องกำไร:** เลนส์ Offers ให้ขึ้นราคาและตั้งตามมูลค่าผลลัพธ์ เลนส์ Monopoly เปิดทางให้เปลี่ยนวิธีรับเงิน (ไม่ผ่านสโตร์) เลนส์ Product ให้ทดสอบการจ่ายเงินจริงก่อนตัดสิน
- **สิ่งที่สร้างเสร็จแล้ว:** เลนส์ Product ให้คะแนนรายละเอียดด้านความไว้ใจที่ทำไว้ก่อนมีลูกค้า เลนส์ Monopoly มองว่าทั้งหมดนั้นเป็น "การห่อ" ที่ลอกได้

## 5. เวอร์ชันที่แข็งแรงที่สุดที่บอร์ดมองเห็น

ไม่ใช่ "ผู้ช่วยทำทุกอย่างบนเว็บสำหรับคนไทยทุกคน" แบบที่เสนอมา แต่เป็น **บริการเดียวสำหรับคนกลุ่มเดียว ที่ขายความไว้ใจ**: เลือกงานหนึ่งประเภทที่ลูกค้าเสียเงินจริงถ้าได้ข้อมูลผิด ทำงานนั้นให้แม่นกว่าที่เขาทำเอง ตั้งราคาตามเงินที่ช่วยประหยัด ไม่ใช่ตามขนาดงาน และใช้คำสัญญาที่มีอยู่แล้ว (บอกราคาก่อน ล้มเหลวไม่คิดเงิน มีหลักฐานเปิดดูเองได้ ผิดคืนเงิน) เป็นตัวแบรนด์ สิ่งที่อาจกันคนลอกได้ในระยะยาวคือชื่อเสียงด้านความแม่นและข้อมูลว่างานแบบไหนคนไทยสั่งซ้ำ ซึ่งต้องเริ่มเก็บตั้งแต่การทดลองรอบนี้
