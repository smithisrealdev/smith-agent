# แบรนด์: Smith

วันที่ 22 พ.ย. 2026 อ่านจาก `idea.md`, `marketing.md` (ตำแหน่งแบบ A), `competitors.md`, `panel/results.md`, `panel-v2/results.md`, `offer.md`, `customer.json` และสิ่งที่มีอยู่แล้วในแอป (สี ฟอนต์ มาสคอตช้าง ไอคอนแอป)

**ข้อจำกัดที่ต้องรู้ก่อนอ่าน**
- **แบรนด์ไม่ได้เริ่มจากศูนย์:** แอปที่ขึ้น Render แล้วใช้ชื่อ Smith สีน้ำเงิน-เหลือง ฟอนต์ Mitr กับ Prompt และมาสคอตช้างอยู่แล้ว เอกสารนี้จึงตรวจว่าของเดิมเข้ากับตำแหน่งที่เลือกไหม และบอกว่าต้องเปลี่ยนอะไร ไม่ได้ออกแบบใหม่ทั้งหมด
- **ยังไม่มีผู้ใช้จริง:** ตอนนี้เปลี่ยนชื่อยังถูกที่สุดแล้ว หลังเปิดรอบทดลองจะแพงขึ้นทุกวัน
- **การตรวจชื่อเป็นการค้นสาธารณะเท่านั้น:** ผมตรวจโดเมนผ่านระบบของ GoDaddy ได้ ส่วนเครื่องหมายการค้าและชื่อบัญชีโซเชียล ผมค้นจากเครื่องนี้ไม่ได้ ต้องให้คุณค้นเองตามลิงก์ในข้อ 2 **นี่ไม่ใช่คำแนะนำทางกฎหมาย** ทนายด้านเครื่องหมายการค้าเป็นคนยืนยัน และไม่มีอะไรเป็นของคุณจนกว่าจะจดทะเบียน

## 1. แบรนด์ต้องพูดอะไร

ตำแหน่งที่เลือก (`marketing.md` แบบ A):

> สำหรับเจ้าของร้านเล็กและฟรีแลนซ์ ที่ต้องเปิดหลายแท็บเทียบราคาของชิ้นใหญ่เอง **ประกันราคา Smith** คือผู้ช่วยใน LINE ที่เทียบราคาข้ามร้านพร้อมหลักฐานให้เปิดตรวจเอง และคืนเงินเมื่อราคาไม่ตรงหน้าเว็บ ต่างจากการถาม AI ทั่วไปที่ตอบฟรีแต่ไม่มีใครรับผิดชอบคำตอบ

เหตุผลที่ผู้ซื้อจำลองลอง (ไม่ใช่จ่าย) จาก `panel-v2`: มีคนรับผิดชอบเมื่อราคาผิด, หลักฐานเปิดตรวจได้, ลองฟรีก่อน, โค้ดส่วนลด, ส่งให้คนที่ไว้ใจดูได้ ข้อที่ทำให้ไม่ซื้อมากที่สุดคือ "ไม่ไว้ใจ" กับ "ของฟรีทำได้อยู่แล้ว"

**สรุป: แบรนด์ขายความไว้ใจ ไม่ใช่ความฉลาดของ AI** ทุกอย่างในเอกสารนี้ตัดสินด้วยคำถามเดียว: ทำให้คนเชื่อตัวเลขที่ Smith ส่งให้มากขึ้นไหม

### คำแนะนำ: ใช้ "Smith" ต่อ แต่ไม่ใช้ "Smith Agent" เป็นชื่อที่ลูกค้าเห็น

- ตลอดรอบทดลองใช้ "Smith" ต่อ เพราะสร้างไว้ครบแล้ว และยังไม่มีชื่ออื่นที่ดีกว่าชัดเจน ชื่อภาษาไทยสองชื่อที่คัดไว้เป็นคำทั่วไป ซึ่งยากกว่าในการจดเป็นเครื่องหมาย
- ตัดคำว่า **Agent** ออกจากชื่อที่ลูกค้าเห็น แอป ข้อความ LINE และโพสต์ใช้ **"Smith"** หรือ **"ประกันราคา Smith"** เหตุผลสองข้อ:
  - "Smith Agent" ใกล้กับตัวร้าย AI ในหนังที่หลายคนรู้จัก ซึ่งขัดกับแบรนด์ที่ขายความไว้ใจ
  - คำว่า Agent ไม่ได้บอกอะไรกับลูกค้า
- ชื่อในโค้ดและบน Render ไม่ต้องเปลี่ยน
- **ก่อนเปิดให้คนนอกวงเพื่อน** ให้ค้น "Smith" และ "สมิธ" ในทะเบียนเครื่องหมายการค้าไทย ในจำพวกด้านล่าง ถ้ามีเครื่องหมายเดียวกันหรือคล้ายในจำพวกเดียวกัน ให้คุยกับทนายก่อนลงทุนกับชื่อนี้ ถ้าต้องเปลี่ยน ให้เปลี่ยนก่อนเปิดรอบใหญ่ (วัน D ใน `marketing.md`)

## 3. คำสัญญา น้ำเสียง และสโลแกน

### คำสัญญาบรรทัดเดียว (เป็นจริงทุกงานในระบบวันนี้)

> **บอกราคาก่อนเริ่ม ไม่สำเร็จไม่คิดเงิน และทุกตัวเลขมีลิงก์ให้คุณเปิดตรวจเอง**

ประโยคนี้เป็นจริงทุกงานในระบบวันนี้ ส่วนสิ่งที่ห้ามใส่ในคำสัญญา (ตาม `marketing.md` ข้อ 3):
- "ถูกที่สุด"
- "ครอบคลุม Shopee/Lazada"
- "มีภาพหน้าจอทุกงาน": ภาพหน้าจอมีเฉพาะเมื่อเปิดหน้าเว็บได้
- "ไม่เอาไปฝึก AI": ต้องรอทนายตรวจก่อน

### สโลแกน 3 แบบ

1. **"เช็กให้ ตรวจได้ ผิดคืนเงิน"** สามจังหวะ ตรงกับสามคำสัญญา (ผมแนะนำแบบนี้)
2. **"ราคาที่มีหลักฐาน"** สั้นที่สุด ใช้ได้กับไอคอนและป้าย
3. **"ให้ Smith เปิดแท็บแทนคุณ"** เล่าภาพปัญหาของกลุ่มเทียบราคา แต่ไม่ได้พูดเรื่องความไว้ใจ

"ผิดคืนเงิน" ในแบบที่ 1 ต้องอ่านคู่กับเงื่อนไข: ขอได้ภายใน 24 ชั่วโมง และคืนอัตโนมัติได้ตามจำนวนครั้งต่อเดือน ในโพสต์ให้ใส่เงื่อนไขไว้ใกล้ๆ เสมอ

### น้ำเสียง: 3 คำ

| คำ | ทำ | ไม่ทำ |
|---|---|---|
| **ตรงไปตรงมา** | บอกตัวเลขจริง บอกสิ่งที่ทำไม่ได้ก่อนลูกค้าถาม ("อ่าน Shopee ไม่ได้ ราคาจากเว็บนี้อาจไม่อยู่ในผล") | ไม่ใช้คำโฆษณาเกินจริง ("ถูกสุดแน่นอน", "AI อัจฉริยะ") ไม่ซ่อนเงื่อนไขไว้ท้าย |
| **อุ่นใจ** | พูดเหมือนเพื่อนที่เก่งเรื่องเทียบราคา ใช้ "ครับ" สุภาพแต่ไม่แข็ง ขอโทษตรงๆ เมื่อผิด ("ราคาไม่ตรงเป็นความผิดของ Smith ขอโทษด้วยครับ") | ไม่โทษลูกค้า ไม่ใช้ศัพท์เทคนิค (โมเดล, โทเค็น, API) ไม่ใช้อีโมจิเยอะจนดูไม่จริงจังเรื่องเงิน |
| **กระชับ** | หนึ่งประโยคหนึ่งเรื่อง ตัวเลขขึ้นก่อนคำอธิบาย | ไม่เขียนย่อหน้ายาวในแชท ไม่เกริ่นนำ |

**ตัวอย่างเขียนใหม่** (จาก `pitch.md` บรรทัดแรก)

- ก่อน: "ประกันราคา Smith ผู้ช่วยใน LINE ที่ไปเช็กราคาข้ามร้านให้ แล้วส่งตัวเลือกที่ถูกที่สุดไม่เกิน 3 อย่าง พร้อมลิงก์หน้าเว็บจริง ภาพหน้าจอ และโค้ดส่วนลดที่เจอบนหน้าเว็บ"
- หลัง: "พิมพ์ของที่จะซื้อใน LINE Smith เปิดหลายร้านเทียบให้ ส่งกลับ 3 ตัวเลือกพร้อมลิงก์ให้คุณเปิดตรวจเอง ราคาไม่ตรงหน้าเว็บ คืนเงิน"
- เปลี่ยนอะไร:
  - ตัดคำว่า "ถูกที่สุด" ซึ่งรับประกันไม่ได้
  - ตัด "ภาพหน้าจอ" ซึ่งไม่ได้มีทุกงาน
  - เริ่มประโยคด้วยสิ่งที่ลูกค้าทำ
  - ปิดท้ายด้วยคำสัญญาที่รับผิดชอบ

### โลโก้ (บรีฟ)

**ของที่มีแล้ว:** หัวช้างสีน้ำเงินบนพื้นเหลือง เป็นไอคอนแอป (`public/icon-180.png`) และมาสคอตในแอป ใช้ได้ดีที่ขนาดเล็ก และเป็นภาพที่คนไทยคุ้น

**โลโก้ต้องบอก:** เพื่อนที่ไว้ใจได้ ไปดูมาแล้ว มีหลักฐาน ไม่ใช่หุ่นยนต์ ไม่ใช่ร้านขายของ

**ต้องใช้ได้ที่:**
- ไอคอนโปรไฟล์ LINE OA ซึ่งถูกตัดเป็น**วงกลม** (สำคัญที่สุด) หัวช้างตอนนี้ออกแบบมาสำหรับสี่เหลี่ยมมุมมน ต้องตรวจว่าหูไม่ถูกตัดเมื่อครอปเป็นวงกลม
- ไอคอนแอป 32px และ favicon
- ภาพหัววิดีโอสั้น
- สติกเกอร์บนหน้าจอผลงาน

**ต้องหลีกเลี่ยง:**
- ช้างที่ดูคล้ายช้างของเบียร์ช้าง หรือแบรนด์ไทยอื่นที่ใช้ช้าง ให้ทนายดูตอนค้นเครื่องหมาย
- สีเขียว LINE
- ภาพหุ่นยนต์หรือสมองกล ซึ่งตรงข้ามกับ "อุ่นใจ"
- แว่นขยายหรือรถเข็นสินค้าแบบที่เว็บเทียบราคาทุกเจ้าใช้

**ที่ยังขาด:** โลโก้ตัวอักษร "Smith" ที่ใช้คู่กับหัวช้าง เสนอให้ใช้ Mitr หนา 700 สีน้ำหมึก ไม่ต้องดัดแปลงตัวอักษร ผมช่วยสร้างแบบร่างด้วยเครื่องมือสร้างภาพได้ถ้าคุณต้องการ แบบร่างที่ได้เป็นแนวคิด ไม่ใช่โลโก้ที่พร้อมจดทะเบียน

### 5 จุดแรกที่ลูกค้าเห็น

ผมปรับจุดของร้านที่มีหน้าร้าน (ป้าย บรรจุภัณฑ์ ใบเสร็จ) ให้เข้ากับบริการในแชท

1. **ป้ายหน้าร้าน = หน้าแรกของแอปและข้อความต้อนรับใน LINE**
   - ตอนนี้: "อยากให้ Smith ช่วยอะไรวันนี้" และตัวอย่างงานกลุ่มละหนึ่งงาน
   - เพิ่มสโลแกน "เช็กให้ ตรวจได้ ผิดคืนเงิน" หนึ่งบรรทัดในข้อความต้อนรับของ LINE
2. **บรรจุภัณฑ์ = การ์ดใบเสนอราคา**
   - หน้าที่ของมันคือบอกแผน ราคา และ "ไม่สำเร็จไม่คิดเงิน" ก่อนลูกค้ากดเริ่ม
   - ใช้พื้นเหลืองเฉพาะตรงราคา
3. **ใบเสร็จ = ผลงาน**
   - ทุกตัวเลือกมีลิงก์ร้าน มีเวลาที่เช็ก มีจำนวนเว็บที่อ่าน และเว็บที่อ่านไม่ได้
   - ปุ่ม "ส่งให้เพื่อนดู" คือการบอกต่อที่ไม่ต้องจ่ายค่าโฆษณา
4. **โพสต์แรก = ตะขอ H1 ใน `marketing.md`**
   - ผลเทียบราคาจริงหนึ่งงาน พร้อมลิงก์และเวลาที่เช็ก
   - บอกด้วยว่าอ่านเว็บไหนไม่ได้
   - ห้ามแต่งตัวเลข
5. **คำตอบต่อคำร้องเรียนแรก** (ใช้เป็นแบบได้เลย)
   > "ขอโทษครับ ราคาที่ Smith ส่งไปไม่ตรงกับหน้าเว็บ เป็นความผิดของ Smith เอง คืน ฿9 เข้าเครดิตแล้ว ผมเปิดหน้านั้นดูแล้ว ตอนนี้ราคาอยู่ที่ [ราคา] ขอบคุณที่บอก จะเอาไปแก้ให้ Smith เช็กแม่นขึ้นครับ"
   - ยอมรับก่อน คืนเงินก่อนอธิบาย
   - บอกว่าตรวจแล้วเห็นอะไร
   - ไม่โทษเว็บร้าน
