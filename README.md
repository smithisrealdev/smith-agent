# Smith Agent: บอท LINE สำหรับทดลอง (MVP)

สั่งงานบนเว็บผ่าน LINE ได้แบบนี้:

1. Smith บอกแผนและราคาก่อนเริ่ม
2. Agent ใช้ Claude ค้นและอ่านเว็บให้
3. Smith ส่งผลพร้อมหลักฐาน
4. ถ้าไม่สำเร็จไม่คิดเงิน และขอคืนเงินเป็นเครดิตได้ถ้าผลไม่ตรง

เวอร์ชันนี้ทำไว้**ทดลอง**: ให้คนจริงใช้ 50–100 งาน แล้ววัดว่า Smith ทำงานสำเร็จกี่ % และต้นทุนต่องานต่ำกว่าราคาที่ตั้งไว้ไหม ผลที่ได้ใช้ตัดสินว่าควรสร้างแอปเต็มตามดีไซน์ต่อหรือไม่

ดีไซน์แอปเต็ม: https://claude.ai/artifact/7By4DNTRLDHtDxY28R5XVd (ลิงก์ส่วนตัว ต้องได้รับสิทธิ์เข้าถึง)

## ผู้ใช้เจออะไร

1. **พิมพ์งาน** เช่น "หาตั๋วไปเชียงใหม่ศุกร์นี้ ถูกสุด"
   - Smith ตอบแผน ราคา และเวลาโดยประมาณ พร้อมปุ่ม **เริ่มงาน** กับ **ยกเลิก**
   - งานที่ทำไม่ได้ (ต้องล็อกอิน จ่ายเงิน หรือโทร) Smith ปฏิเสธโดยไม่คิดเงิน
2. **กดเริ่มงาน:** Smith กันเครดิตไว้เท่าราคา แล้วให้ Claude ใช้ web search กับ web fetch ทำงาน
3. **ได้ผลลัพธ์:**
   - **สำเร็จ:** ส่งคำตอบ ลิงก์หลักฐาน และภาพหน้าจอ (ถ้าตั้งค่าไว้) มาในแชท พร้อมปุ่ม **ผลไม่ตรง ขอเงินคืน**
   - **ไม่สำเร็จ:** คืนเครดิตทั้งหมด
4. **ขอเงินคืน:** ทำได้ภายใน 24 ชั่วโมง คืนอัตโนมัติเดือนละ 3 ครั้ง เกินนั้นเข้าคิวให้ทีมงานตรวจ
5. **พิมพ์ "เครดิต":** ดูยอดคงเหลือและรหัสผู้ใช้ (ใช้ตอนขอเติมเครดิต)

ราคาแบ่งตามขนาดงานที่ Claude ประเมิน:

| ขนาด | ราคา | ค้นเว็บได้ | เปิดอ่านหน้าเว็บได้ |
|---|---|---|---|
| S งานเช็กเร็ว | ฿5 | 3 ครั้ง | 2 หน้า |
| M เทียบหลายแหล่ง | ฿9 | 6 ครั้ง | 4 หน้า |
| L อ่านเยอะ | ฿15 | 10 ครั้ง | 6 หน้า |

ผู้ใช้ใหม่ได้เครดิต ฿20 (งานแรกฟรี) ช่วงทดลองยังไม่มีระบบจ่ายเงิน ทีมงานเติมเครดิตให้ผู้ทดลองเอง

## ติดตั้ง

ต้องใช้ Node.js 22.13 ขึ้นไป

1. **สร้าง LINE Official Account:** สร้างช่อง Messaging API ใน [LINE Developers](https://developers.line.biz/console/)
   - เก็บ **Channel secret** และออก **Channel access token (long-lived)**
   - ใน LINE Official Account Manager ให้**ปิด**ข้อความตอบกลับอัตโนมัติและข้อความทักทาย (บอทส่งข้อความต้อนรับเอง) แล้ว**เปิด** Webhook
2. **สร้าง API key ของ Claude** ที่ [Claude Console](https://platform.claude.com/)
3. **ติดตั้งและใส่ค่า:**

```bash
npm install
```

```bash
cp .env.example .env
```

แล้วใส่ `LINE_CHANNEL_SECRET`, `LINE_CHANNEL_ACCESS_TOKEN` และ `ANTHROPIC_API_KEY` ใน `.env`

4. **รันเซิร์ฟเวอร์:**

```bash
npm start
```

5. **เปิดให้ LINE เรียกได้ทาง HTTPS:** เช่นใช้ Cloudflare Tunnel ตอนทดลอง หรือรันบนโฮสต์ที่มี HTTPS
   - ตั้ง Webhook URL ใน LINE Developers เป็น `https://<โดเมนของคุณ>/webhook` แล้วกด Verify

```bash
cloudflared tunnel --url http://localhost:3000
```

6. **(ไม่บังคับ) เปิดภาพหน้าจอหลักฐาน:** ติดตั้ง Playwright แล้วใส่ `PUBLIC_URL` เป็นที่อยู่ HTTPS ของเซิร์ฟเวอร์ใน `.env`

```bash
npm install playwright
```

```bash
npx playwright install --with-deps chromium
```

## ดูผลการทดลอง

```bash
npm run stats
```

บอกตัวเลขเหล่านี้:
- จำนวนงานที่เสนอราคา เริ่ม สำเร็จ ไม่สำเร็จ และขอคืนเงิน
- อัตราสำเร็จ อัตราขอคืนเงิน และเวลากลางต่องาน
- รายได้ ต้นทุน Claude จริง ต้นทุนต่องาน และกำไร ทั้งก่อนและหลังหัก VAT กับค่าธรรมเนียมสโตร์ 15% (ตอนขายเครดิตผ่าน App Store / Google Play จริง)
- จำนวนผู้ใช้ และคนที่กลับมาใช้ซ้ำ

เกณฑ์ตัดสินใจที่แนะนำ:
- **ถ้าอัตราสำเร็จต่ำ:** เปลี่ยนงานหลักไปเป็นงานที่ Smith ทำได้ดี
- **ถ้าต้นทุนต่องานสูงกว่าราคาหลังหักค่าธรรมเนียม:** ขึ้นราคา ลดงบค้นเว็บใน `src/config.js` หรือเปลี่ยนรุ่น Claude

## คำสั่งทีมงาน

เติมเครดิตให้ผู้ทดลอง (ผู้ใช้พิมพ์ "เครดิต" ในแชทเพื่อดูรหัส):

```bash
node --disable-warning=ExperimentalWarning src/cli.js grant <รหัสผู้ใช้ LINE> 100
```

อนุมัติคำขอคืนเงินที่รอตรวจ:

```bash
node --disable-warning=ExperimentalWarning src/cli.js refund <เลขงาน>
```

## ตั้งค่า

ค่าทั้งหมดอยู่ใน `.env` (ดู `.env.example`) และ `src/config.js`:

| ค่า | ค่าเริ่มต้น | ใช้ทำอะไร |
|---|---|---|
| `SMITH_MODEL` | `claude-opus-5-5` | รุ่น Claude ที่ใช้ทั้งประเมินราคาและทำงาน ถ้าต้นทุนสูงเกินลองใช้ `claude-sonnet-5-5` หรือ `claude-haiku-5-5` แล้วเทียบผลด้วย `npm run stats` |
| `START_CREDIT` | `20` | เครดิตเริ่มต้นของผู้ใช้ใหม่ |
| `USD_THB` | `36` | อัตราแลกเปลี่ยน ใช้คิดต้นทุน Claude เป็นบาท |
| `PUBLIC_URL` | ว่าง | ที่อยู่ HTTPS ของเซิร์ฟเวอร์ ใช้ส่งภาพหน้าจอหลักฐานเข้า LINE |
| `SIZES` ใน `src/config.js` | ตามตารางด้านบน | ราคาและงบการค้นเว็บของแต่ละขนาดงาน |
| `REFUND` ใน `src/config.js` | 24 ชั่วโมง, 3 ครั้ง/เดือน | กติกาคืนเงินอัตโนมัติ |

ถ้า Claude ปฏิเสธคำขอด้วยเหตุผลด้านความปลอดภัย API จะส่งคำขอนั้นไปให้รุ่นสำรองที่ Anthropic แนะนำทำแทนอัตโนมัติ (server-side fallback)

## สิ่งที่เวอร์ชันนี้ยังไม่มี

- **ระบบจ่ายเงิน:** ช่วงทดลองทีมงานเติมเครดิตเอง ตอนทำแอปจริงจะขายเครดิตผ่าน App Store / Google Play ตามดีไซน์
- **งานที่ต้องล็อกอิน จอง หรือจ่ายเงินแทนผู้ใช้:** Smith ทำแค่ส่วนค้นหาแล้วให้ผู้ใช้ทำต่อเอง
- **การเบลอข้อมูลส่วนตัวในภาพหน้าจอ:** ตอนนี้แคปเฉพาะหน้าเว็บสาธารณะ ไม่มีหน้าที่ล็อกอิน
- **คิวงาน:** ทุกงานรันพร้อมกันบนเครื่องเดียวและเก็บข้อมูลใน SQLite เหมาะกับผู้ทดลองไม่กี่สิบคน ถ้าเซิร์ฟเวอร์รีสตาร์ตระหว่างทำงาน งานนั้นจะถูกยกเลิกและคืนเครดิตให้อัตโนมัติ
- **การเปิดหน้าเว็บซ้ำเพื่อเช็กราคาก่อนส่งผล**

## โครงสร้างโค้ด

| ไฟล์ | หน้าที่ |
|---|---|
| `src/server.js` | รับ webhook จาก LINE (ตรวจลายเซ็น) และส่งไฟล์ภาพหลักฐาน |
| `src/bot.js` | ลำดับการคุย: เสนอราคา เริ่มงาน ส่งผล คืนเงิน |
| `src/agent.js` | เรียก Claude: ประเมินราคา และทำงานด้วย web search / web fetch |
| `src/db.js` | เครดิตและงานใน SQLite ทุกการเปลี่ยนยอดมีบันทึกใน `ledger` |
| `src/evidence.js` | แคปหน้าจอหลักฐานด้วย Playwright เฉพาะเว็บสาธารณะ |
| `src/stats.js`, `src/cli.js` | ตัวเลขการทดลองและคำสั่งทีมงาน |
| `src/line.js` | เรียก LINE Messaging API |
