# Smith Agent (MVP)

สั่งงานบนเว็บได้แบบนี้:

1. Smith บอกแผนและราคาก่อนเริ่ม
2. Agent ใช้ Claude ค้นและอ่านเว็บให้
3. Smith ส่งผลพร้อมหลักฐาน
4. ถ้าไม่สำเร็จไม่คิดเงิน และขอคืนเงินเป็นเครดิตได้ถ้าผลไม่ตรง

ใช้ได้ 2 ทาง:
- **เว็บแอปบนมือถือ** หน้าตาตามดีไซน์
- **บอท LINE** (ไม่บังคับ)

ทั้งสองทางใช้เครดิตและกติกาเดียวกัน

เวอร์ชันนี้ทำไว้**ทดลอง**: ให้คนจริงใช้ 50–100 งาน แล้ววัดว่า Smith ทำงานสำเร็จกี่ % และต้นทุนต่องานต่ำกว่าราคาที่ตั้งไว้ไหม

ดีไซน์แอปเต็ม: https://claude.ai/artifact/7By4DNTRLDHtDxY28R5XVd (ลิงก์ส่วนตัว ต้องได้รับสิทธิ์เข้าถึง)

## ทดสอบบนมือถือ (เริ่มตรงนี้)

ต้องมี Node.js 22.13 ขึ้นไปบนคอมพิวเตอร์ และ API key ของ Claude จาก [Claude Console](https://platform.claude.com/) ส่วน LINE ไม่ต้องใช้

1. **ติดตั้ง:**

```bash
npm install
```

```bash
cp .env.example .env
```

แล้วใส่ `ANTHROPIC_API_KEY` ใน `.env` ช่องของ LINE เว้นว่างไว้ได้

2. **รันเซิร์ฟเวอร์:**

```bash
npm start
```

เปิด http://localhost:3000 บนคอมเพื่อเช็กว่าขึ้น

3. **เปิดบนมือถือ:** ต่อ Wi-Fi วงเดียวกับคอม แล้วเปิด `http://<IP ของคอม>:3000`
   - ถ้าเครื่องถามเรื่อง firewall ให้กดอนุญาต

หา IP บน Mac:

```bash
ipconfig getifaddr en0
```

บน Windows ใช้คำสั่ง `ipconfig` แล้วดูบรรทัด IPv4

4. **เพิ่มลงหน้าจอหลัก:** จะใช้งานเหมือนแอป
   - iPhone: กดแชร์ แล้วเลือก "เพิ่มไปยังหน้าจอโฮม"
   - Android: เมนู Chrome แล้วเลือก "เพิ่มลงในหน้าจอหลัก"

5. **เติมเครดิต:** เครื่องใหม่ได้เครดิต ฿20 ถ้าอยากทดสอบมากกว่านั้น ดูรหัสในหน้า "เครดิต" ของแอป แล้วรัน:

```bash
node --disable-warning=ExperimentalWarning src/cli.js grant <รหัสจากหน้าเครดิต> 200
```

**ลองให้ครบทุกทาง:**
- สั่งงานจริง 1 งาน: ดูหน้าราคา กดเริ่ม แล้วรอผลพร้อมลิงก์หลักฐาน
- ขอเงินคืนจากหน้าผลงาน
- สั่งงานที่ Smith ทำไม่ได้ เช่น "โอนเงินให้แม่" ต้องปฏิเสธโดยไม่คิดเงิน
- ลบบัญชีในหน้าตั้งค่า

**ถ้าจะให้คนนอกบ้านลองผ่านอินเทอร์เน็ต** (เช่นผ่าน Cloudflare Tunnel) ให้ตั้ง `WEB_INVITE_CODE` ใน `.env` ก่อน ไม่งั้นใครได้ลิงก์ก็ใช้เครดิต Claude ของคุณได้

```bash
cloudflared tunnel --url http://localhost:3000
```

## ผู้ใช้เจออะไร

1. **พิมพ์งาน** เช่น "หาตั๋วไปเชียงใหม่ศุกร์นี้ ถูกสุด"
   - Smith ตอบแผน ราคา และเวลาโดยประมาณ ให้กด**เริ่มงาน**หรือ**แก้คำสั่ง**
   - งานที่ทำไม่ได้ (ต้องล็อกอิน จ่ายเงิน หรือโทร) Smith ปฏิเสธโดยไม่คิดเงิน
2. **กดเริ่มงาน:** Smith กันเครดิตไว้เท่าราคา แล้วให้ Claude ใช้ web search กับ web fetch ทำงาน ปิดแอประหว่างรอได้
   - ในแอปเห็นทีละขั้นว่า Agent กำลังค้นอะไร หรือเปิดอ่านเว็บไหน ส่วนหน้าแรกมีการ์ดงานที่กำลังทำ แตะเพื่อดูได้
3. **ได้ผลลัพธ์:**
   - **สำเร็จ:** ได้คำตอบ การ์ดตัวเลือกไม่เกิน 3 อัน (รูปสินค้าถ้าหน้าเว็บมีให้ โลโก้แบรนด์ ชื่อ ราคา ลิงก์ อันแรกคืออันที่แนะนำ) ลิงก์หลักฐาน และภาพหน้าจอ (ถ้าติดตั้ง Playwright) พร้อมปุ่ม**ทำงานนี้อีกครั้ง**กับ**ผลไม่ตรง ขอเงินคืน**
   - **ไม่สำเร็จ:** คืนเครดิตทั้งหมด และบอกว่าเกิดอะไรขึ้น
4. **ขอเงินคืน:** ทำได้ภายใน 24 ชั่วโมง คืนอัตโนมัติเดือนละ 3 ครั้ง เกินนั้นเข้าคิวให้ทีมงานตรวจ เหตุผลที่ผู้ใช้เลือกถูกเก็บไว้ใช้ปรับ Agent

ราคาแบ่งตามขนาดงานที่ Claude ประเมิน:

| ขนาด | ราคา | ค้นเว็บได้ | เปิดอ่านหน้าเว็บได้ |
|---|---|---|---|
| S งานเช็กเร็ว | ฿5 | 3 ครั้ง | 2 หน้า |
| M เทียบหลายแหล่ง | ฿9 | 6 ครั้ง | 4 หน้า |
| L อ่านเยอะ | ฿15 | 10 ครั้ง | 6 หน้า |

## เพิ่มบอท LINE (ไม่บังคับ)

1. **สร้างบัญชี LINE OA:** สร้างที่ [LINE Official Account Manager](https://manager.line.biz) (LINE ไม่ให้สร้างช่อง Messaging API ตรงๆ ใน LINE Developers แล้ว)
2. **เปิด Messaging API:** ในบัญชี OA ไปที่ **ตั้งค่า > Messaging API** กด **เปิดใช้** แล้วสร้าง Provider ใหม่หรือเลือก Provider เดิม ถ้าจะใช้เข้าสู่ระบบด้วย LINE ภายหลัง ต้องใช้ Provider เดียวกัน
3. **ตั้งการตอบกลับ:** ใน OA Manager ที่ **ตั้งค่าการตอบกลับ** ให้**ปิด**ข้อความตอบกลับอัตโนมัติและข้อความทักทาย แล้ว**เปิด** Webhook
4. **เก็บคีย์:** ใน [LINE Developers](https://developers.line.biz/console/) เปิดช่องที่เพิ่งสร้าง
   - แท็บ **Basic settings:** คัดลอก **Channel secret**
   - แท็บ **Messaging API:** ออก **Channel access token (long-lived)**
   - ใส่ทั้งสองค่าใน `.env` เป็น `LINE_CHANNEL_SECRET` และ `LINE_CHANNEL_ACCESS_TOKEN` (บน Render ใส่ในแท็บ **Environment**)
5. **ตั้ง Webhook URL:** ในแท็บ **Messaging API** ตั้งเป็น `https://<โดเมนของคุณ>/webhook` (LINE ต้องใช้ HTTPS) กด **Verify** แล้วเปิด **Use webhook**

ในแชท LINE ผู้ใช้พิมพ์ "เครดิต" เพื่อดูยอดและรหัสผู้ใช้ได้

## เข้าสู่ระบบด้วย LINE (ก่อนเปิดให้คนนอกใช้)

ถ้าไม่ตั้งค่า แต่ละเครื่องจะเป็นบัญชีของตัวเอง เหมาะกับทดสอบเองที่บ้าน พอตั้งค่าแล้ว ทุกเครื่องต้องเข้าสู่ระบบด้วย LINE ก่อนใช้

- บัญชีและเครดิตจะตามคนไปทุกเครื่อง
- เปลี่ยนเครื่องแล้วไม่ได้เครดิตฟรีซ้ำ
- ผลงานส่งเข้าแชท LINE ให้ด้วยเมื่อเปิดบอท LINE ไว้

1. **สร้างช่อง LINE Login:** ใน [LINE Developers](https://developers.line.biz/console/) สร้างช่อง LINE Login ไว้ใต้ provider เดียวกับช่อง Messaging API ของบอท (ผู้ใช้คนเดียวกันจะได้รหัสเดียวกันทั้งสองช่อง)
2. **ตั้ง Callback URL:** เป็น `https://<โดเมนของคุณ>/auth/line/callback` (ต้องเป็น HTTPS)
3. **ผูกบัญชี LINE OA:** ที่หน้า "Linked LINE Official Account" ผูกกับบัญชีของบอท ผู้ใช้จะได้ปุ่มเพิ่มเพื่อนตอนเข้าสู่ระบบ
4. **ใส่ค่าใน `.env`:** `LINE_LOGIN_CHANNEL_ID`, `LINE_LOGIN_CHANNEL_SECRET` และ `PUBLIC_URL` (บน Render ใส่สองค่าแรกในแท็บ **Environment** ส่วน `PUBLIC_URL` Render ตั้งให้เอง)
5. **เผยแพร่ช่อง:** ช่องใหม่อยู่ในโหมด **Developing** ซึ่งเข้าสู่ระบบได้เฉพาะแอดมินของช่อง กด **Publish** ก่อนส่งรหัสเชิญให้ผู้ทดลอง

ผมเขียนส่วนนี้ตาม LINE Login v2.1 แต่เปิดเอกสารของ LINE จากเครื่องที่ใช้พัฒนาไม่ได้ จึงทดสอบกับ LINE จำลองเท่านั้น การเข้าสู่ระบบจริงครั้งแรกคือการทดสอบจริง

## ภาพหน้าจอหลักฐาน (ไม่บังคับ)

ติดตั้ง Playwright บนเครื่องที่รันเซิร์ฟเวอร์:

```bash
npm install playwright
```

```bash
npx playwright install --with-deps chromium
```

- เว็บแอปแสดงภาพได้เลย
- บอท LINE ต้องใส่ `PUBLIC_URL` เป็นที่อยู่ HTTPS ของเซิร์ฟเวอร์ด้วย
- เมื่อมี `PUBLIC_URL` และตัวเลือกมีรูปสินค้า (JPEG หรือ PNG) บอทส่งตัวเลือกเป็นการ์ดเลื่อนได้ แต่ละใบมีรูป ชื่อ ราคา และปุ่ม**เปิดดู** ถ้า LINE ไม่รับการ์ด บอทส่งผลเป็นข้อความแทน
- ไฟล์ภาพตั้งชื่อแบบสุ่มที่เดาไม่ได้ และเบราว์เซอร์จะไม่โหลดเว็บที่ชี้ไป IP ภายใน

## ขึ้นเซิร์ฟเวอร์จริง (Docker)

`Dockerfile` รวมเว็บแอป API บอท LINE และ Chromium สำหรับภาพหลักฐานไว้ในตัวเดียว รันด้วยผู้ใช้ที่ไม่ใช่ root

สร้าง image:

```bash
docker build -t smith-agent .
```

รัน:

```bash
docker run -d --name smith -p 3000:3000 --env-file .env -v smith-data:/data smith-agent
```

- **เก็บข้อมูลถาวร:** ต่อ volume ที่ `/data` เสมอ ฐานข้อมูลและภาพหลักฐานอยู่ที่นั่น ถ้าไม่ต่อ ข้อมูลจะหายเมื่อสร้าง container ใหม่
- **HTTPS:** ใช้โฮสต์ที่ให้ HTTPS มาเลย (เช่น Render, Fly.io, Railway) หรือวาง reverse proxy อย่าง Caddy หน้า container บน VPS แล้วใส่ที่อยู่นั้นใน `PUBLIC_URL`
- **ไม่ต้องการภาพหลักฐาน:** ลบ 2 บรรทัด `playwright` ใน `Dockerfile` ได้ image จะเล็กลงมาก

ผมทดสอบ build และรัน image บนเครื่องที่ใช้พัฒนาแล้ว ทุกส่วนผ่าน ยกเว้นขั้นติดตั้ง Chromium เพราะเครือข่ายของเครื่องนั้นบล็อก `deb.debian.org` และ `cdn.playwright.dev` บนเครื่องทั่วไปขั้นนี้ใช้คำสั่งมาตรฐานของ Playwright

## ขึ้นเซิร์ฟเวอร์จากมือถือ (Render)

ทำจากเบราว์เซอร์บนมือถือได้ ไม่ต้องใช้คอม ไฟล์ `render.yaml` ตั้งค่าไว้ให้แล้ว (Docker, ดิสก์ถาวร, ภูมิภาคสิงคโปร์)

1. **เข้า Render:** ไปที่ [dashboard.render.com](https://dashboard.render.com) แล้วเข้าสู่ระบบด้วยบัญชี GitHub ที่เห็น repo นี้
2. **สร้าง Blueprint:** กด **New** แล้วเลือก **Blueprint** เลือก repo `smith-agent`
   - ถ้างานยังอยู่ใน branch `claude/hopeful-galileo-2f7t8e` ให้เลือก branch นั้น หรือ merge เข้า main ก่อน
3. **ใส่ค่า:** Render จะถาม 2 ค่า
   - `ANTHROPIC_API_KEY`
   - `WEB_INVITE_CODE` (รหัสเชิญที่คุณตั้งเอง)

   ใส่แล้วกด **Apply**
4. **เปิดใช้:** รอ build เสร็จ (ครั้งแรกใช้หลายนาที) แล้วเปิดลิงก์ของบริการบนมือถือ ใส่รหัสเชิญ แล้วลองใช้ได้เลย

**ค่าใช้จ่าย:** `render.yaml` ใช้แพ็กเกจ Starter เพราะดิสก์ถาวรใช้กับแพ็กเกจฟรีไม่ได้ ถ้าไม่มีดิสก์ข้อมูลจะหายทุกครั้งที่รีสตาร์ต ดูราคาล่าสุดที่หน้าเว็บของ Render

**เครดิตผู้ทดลอง:** เริ่มที่ ฿200 (`START_CREDIT` ใน `render.yaml`) ไม่ต้องเติมให้ทีละคน

**ดูผลการทดลอง:** เปิดหน้าบริการบน Render แล้วไปที่แท็บ **Shell** จากนั้นรันคำสั่งเหล่านี้

```bash
npm run stats
```

```bash
node --disable-warning=ExperimentalWarning src/cli.js jobs 30
```

**LINE:** เพิ่มค่าของ LINE ในแท็บ **Environment** ทีหลังได้ ส่วน `PUBLIC_URL` ไม่ต้องใส่ เพราะ Render ตั้งให้เอง

ผมเขียน `render.yaml` ตามรูปแบบ Blueprint ของ Render แต่เปิดเอกสารของ Render จากเครื่องที่ใช้พัฒนาไม่ได้ ถ้า Render แจ้งว่าไฟล์ผิด ส่งข้อความนั้นมาให้ผมแก้

## แผนทดลองแบบเชิญ (ก่อนทำระบบจ่ายเงิน)

ยังไม่ทำระบบจ่ายเงินจนกว่าตัวเลขจะยืนยันว่าราคาครอบคลุมต้นทุน ระหว่างนี้ทีมงานเติมเครดิตให้ผู้ทดลองเอง

1. **ขึ้นเซิร์ฟเวอร์:** ใช้ Docker และ HTTPS ตามหัวข้อด้านบน ตั้ง `WEB_INVITE_CODE` และเปิดเข้าสู่ระบบด้วย LINE ถ้าทำได้
2. **ชวนผู้ทดลอง 10–20 คน:** ให้รหัสเชิญ แล้วเติมเครดิตคนละ ฿100–200 ด้วยคำสั่ง `grant` (ผู้ทดลองดูรหัสผู้ใช้ได้ในหน้าเครดิต)
3. **ให้ใช้กับงานจริงของตัวเอง 1–2 สัปดาห์:** เป้าคือ 50–100 งานที่กดเริ่ม
4. **ทุกวัน:** ดูตัวเลขรวม แล้วอ่านงานที่ไม่สำเร็จและเหตุผลที่ขอคืนเงิน เพื่อปรับคำสั่งของ Agent ใน `src/agent.js` หรือราคาใน `src/config.js`

```bash
npm run stats
```

```bash
node --disable-warning=ExperimentalWarning src/cli.js jobs 30
```

`npm run stats` บอกตัวเลขเหล่านี้:
- จำนวนงานที่เสนอราคา เริ่ม สำเร็จ ไม่สำเร็จ และขอคืนเงิน
- อัตราสำเร็จ อัตราขอคืนเงิน และเวลากลางต่องาน
- รายได้ ต้นทุน Claude จริง ต้นทุนต่องาน และกำไร ทั้งก่อนและหลังหัก VAT กับค่าธรรมเนียมสโตร์ 15%
- จำนวนผู้ใช้ และคนที่กลับมาใช้ซ้ำ

เกณฑ์ผ่านที่ผมแนะนำ (ปรับได้ตามเป้าธุรกิจ):

| ตัวเลข | ผ่านเมื่อ | ถ้าไม่ผ่าน |
|---|---|---|
| อัตราสำเร็จ | 80% ขึ้นไป | เปลี่ยนงานหลักไปเป็นงานที่ Smith ทำได้ดี หรือปรับคำสั่งของ Agent |
| กำไรหลังหัก VAT และค่าธรรมเนียมสโตร์ | มากกว่า 0 | ขึ้นราคา ลดงบค้นเว็บใน `src/config.js` หรือเปลี่ยนรุ่น Claude ด้วย `SMITH_MODEL` |
| อัตราขอคืนเงิน | ไม่เกิน 10% | อ่านเหตุผลใน `jobs` แล้วแก้จุดที่ผลไม่ตรงบ่อย |

## ตั้งค่า

ค่าทั้งหมดอยู่ใน `.env` (ดู `.env.example`) และ `src/config.js`:

| ค่า | ค่าเริ่มต้น | ใช้ทำอะไร |
|---|---|---|
| `ANTHROPIC_API_KEY` | ว่าง | ต้องมี ใช้เรียก Claude |
| `LINE_CHANNEL_SECRET`, `LINE_CHANNEL_ACCESS_TOKEN` | ว่าง | ใส่เมื่อจะเปิดบอท LINE ถ้าว่างจะมีแค่เว็บแอป |
| `LINE_LOGIN_CHANNEL_ID`, `LINE_LOGIN_CHANNEL_SECRET` | ว่าง | ใส่พร้อม `PUBLIC_URL` เพื่อบังคับเข้าสู่ระบบด้วย LINE |
| `WEB_INVITE_CODE` | ว่าง | รหัสเชิญของเว็บแอป ตั้งก่อนเปิดให้เข้าจากอินเทอร์เน็ต |
| `QUOTES_PER_HOUR` | `30` | จำนวนครั้งที่ขอราคาได้ต่อคนต่อชั่วโมง (ขอราคาแต่ละครั้งเสียค่า Claude) |
| `SMITH_MODEL` | `claude-opus-5-5` | รุ่น Claude ถ้าต้นทุนสูงเกินลองใช้ `claude-sonnet-5-5` หรือ `claude-haiku-5-5` แล้วเทียบผลด้วย `npm run stats` |
| `START_CREDIT` | `20` | เครดิตเริ่มต้นของผู้ใช้ใหม่ |
| `USD_THB` | `36` | อัตราแลกเปลี่ยน ใช้คิดต้นทุน Claude เป็นบาท |
| `PUBLIC_URL` | ว่าง | ที่อยู่ HTTPS ของเซิร์ฟเวอร์ ใช้ส่งภาพหลักฐานและการ์ดตัวเลือกพร้อมรูปสินค้าเข้า LINE |
| `SIZES` ใน `src/config.js` | ตามตารางด้านบน | ราคาและงบการค้นเว็บของแต่ละขนาดงาน |
| `REFUND` ใน `src/config.js` | 24 ชั่วโมง, 3 ครั้ง/เดือน | กติกาคืนเงินอัตโนมัติ |

ถ้า Claude ปฏิเสธคำขอด้วยเหตุผลด้านความปลอดภัย API จะส่งคำขอนั้นไปให้รุ่นสำรองที่ Anthropic แนะนำทำแทนอัตโนมัติ (server-side fallback)

## ก่อนเปิดให้ผู้ใช้จริง

เวอร์ชันนี้พร้อมให้ทีมงานและผู้ทดลองที่ได้รับเชิญใช้ ก่อนเปิดให้คนทั่วไปยังต้องมี:

- **เปิดเข้าสู่ระบบด้วย LINE:** ทำไว้แล้ว เหลือตั้งค่าตามหัวข้อด้านบน ส่วนเข้าสู่ระบบด้วยเบอร์โทรและ OTP ตามดีไซน์ยังไม่ได้ทำ เพราะต้องใช้ผู้ให้บริการ SMS
- **ระบบจ่ายเงิน:** ขายเครดิตผ่าน App Store / Google Play ตามดีไซน์ ซึ่งต้องห่อเว็บแอปเป็นแอปมือถือ
- **โฮสต์จริง:** มี `Dockerfile` แล้ว เหลือเลือกโฮสต์ที่มี HTTPS, ตั้งสำรองไฟล์ใน `/data` และระบบแจ้งเตือนเมื่อเซิร์ฟเวอร์ล่ม
- **แจ้งเตือนเมื่องานเสร็จ:** ส่งเข้าแชท LINE ได้แล้วเมื่อเปิดทั้ง LINE Login และบอท LINE ถ้าไม่ได้เปิด ต้องกลับมาเปิดแอปดูเอง
- **ให้ทนายตรวจนโยบายความเป็นส่วนตัวและเงื่อนไขการใช้งาน:** ตอนนี้เป็นฉบับร่างที่เขียนจากการทำงานจริงของระบบ (อยู่ใน `public/app.js` ตัวแปร `PRIVACY` และ `TERMS`)
- **ส่วนอื่นของดีไซน์:** เช่น สั่งด้วยเสียง ทำซ้ำอัตโนมัติ ครอบครัว และโหมดร้านค้า

ข้อจำกัดอื่นที่ยังมี:
- งานที่ต้องล็อกอิน จอง หรือจ่ายเงินแทนผู้ใช้ Smith ทำไม่ได้
- ทุกงานรันบนเครื่องเดียว (SQLite) เหมาะกับผู้ทดลองไม่กี่สิบคน
- ถ้าเซิร์ฟเวอร์รีสตาร์ตระหว่างทำงาน งานนั้นจะถูกยกเลิกและคืนเครดิตให้อัตโนมัติ

## โครงสร้างโค้ด

| ไฟล์ | หน้าที่ |
|---|---|
| `public/` | เว็บแอปมือถือ (HTML, CSS, JS ล้วน ไม่ต้อง build) และมาสคอตจากดีไซน์ |
| `src/server.js` | เซิร์ฟเวอร์: เว็บแอป, API, webhook ของ LINE |
| `src/web.js` | API ของเว็บแอป: บัญชี เข้าสู่ระบบ จำกัดจำนวนการขอราคา และรหัสเชิญ |
| `src/linelogin.js` | เข้าสู่ระบบด้วย LINE (OAuth / OpenID Connect) |
| `src/bot.js` | บทสนทนาใน LINE |
| `src/runner.js` | ทำงานหนึ่งงานจนจบ: เรียก Agent แคปหลักฐาน แล้วตัดหรือคืนเครดิต |
| `src/agent.js` | เรียก Claude: ประเมินราคา และทำงานด้วย web search / web fetch |
| `src/db.js` | เครดิตและงานใน SQLite ทุกการเปลี่ยนยอดมีบันทึกใน `ledger` |
| `src/evidence.js` | แคปหน้าจอหลักฐานด้วย Playwright เฉพาะเว็บสาธารณะ |
| `src/image.js` | ดึงรูปสินค้าของแต่ละตัวเลือกจากรูปพรีวิวของหน้าเว็บ (og:image) ฝั่งเซิร์ฟเวอร์ เฉพาะเว็บสาธารณะ ย่อเป็น JPEG ไม่เกิน 800×800 ด้วย sharp (ประหยัดเน็ต และแสดงใน LINE ได้) เก็บคู่กับหลักฐานและลบพร้อมบัญชี หน้าที่ไม่มีรูปจะแสดงโลโก้เว็บแทน |
| `src/logo.js` | เก็บโลโก้ของแบรนด์และเว็บในผลงาน (Agent ระบุแบรนด์ของแต่ละตัวเลือก เช่น AirAsia แม้เจอบนเว็บรวม) ทั้งตอน Agent เปิดอ่านเว็บและตอนงานเสร็จ (ขอจากบริการ favicon ของ Google ฝั่งเซิร์ฟเวอร์ ส่งไปแค่ชื่อเว็บ) เว็บที่ไม่มีโลโก้แอปจะแสดงไอคอนลูกโลกแทน |
| `public/icons.js` | ไอคอนทั้งแอป สร้างจาก Phosphor Icons (MIT) และโลโก้ LINE ด้วย `scripts/gen_icons.py` |
| `src/stats.js`, `src/cli.js` | ตัวเลขการทดลองและคำสั่งทีมงาน |
| `src/line.js` | เรียก LINE Messaging API |
